# Console 设计与当前交付

Next.js Console 在 `/` 展示真实 API 就绪状态与 OpenAPI 文档入口。由 Console 服务端读取 API，数据库、Redis 和检索引擎保留在后端服务网络。

WP-08 在同一 Console 中交付登录入口和两个角色工作区。

| 路径 | 使用者 | 主要流程 |
| --- | --- | --- |
| `/auth` | 受邀用户 | 登录与管理会话 |
| `/admin` | 平台管理员、运维及审计角色 | 查看总览、Provider、请求和审计，按权限管理租户与额度 |
| `/console` | 开发者和租户管理员 | 创建、轮换、吊销密钥，查看用量，在 Playground 检索文字和图片 |

工作区采用 44 px 顶栏、184–200 px 侧栏和弹性主内容区。常规字号控制在 12 px，提供浅色及深色主题，以紧凑表格为主。使用键盘可访问操作、表格筛选与对话框。移动布局优先覆盖查看用量与吊销密钥。页面展示加载、空、降级和权限失败状态，监控数据来自真实 API。

搜索图片的交互优先展示落地页，再列出预览、原图、检索引擎及许可依据。`unknown` 显示“授权未知”，缩略图加载失败时保留来源链接。采用非执行式图片展示，浏览器始终将外部链接与图片视为不可信数据。

浏览器登录采用独立的 HttpOnly 会话 Cookie 和 CSRF 防护。角色权限以服务端判定。密钥明文只在成功创建或轮换时展示一次，列表只显示掩码、作用域和状态。
